# Publish a versioned Markdown contract

Managed documents use the `dsh-personal-os/v1` Frontmatter contract with a Document Kind, prefixed ULID identity, typed source-owned Relations, portable provenance, and distinct local dates versus precise timestamps. Archive state is expressed by directory location, reverse and computed data are projections, and schema migration is always explicit rather than a side effect of scanning; the normative v1 shape lives in `docs/markdown-format.md`.
