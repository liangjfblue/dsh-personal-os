# Compose DSH capabilities instead of building a parallel runtime

Personal OS is embedded in DeepSeek Harness and relies on DSH for agents, sessions, event logs and queries, permissions, tools, skills, system context, background work, settings, credentials, workspaces, Remote communication, and client slots. The plugin owns only the personal domain, Markdown persistence and indexing, projections, and their adapters into those capabilities; Session Event Logs are analyzed as DSH-owned evidence and distilled results become Personal OS domain facts.
